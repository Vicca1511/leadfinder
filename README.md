# LeadFinder

**Sistema de prospecção comercial desenvolvido em Python.**

O LeadFinder é um projeto em desenvolvimento que busca organizar o cadastro e a análise inicial de empresas para apoiar processos de prospecção comercial e priorização de potenciais clientes.

## Objetivo

Desenvolver uma ferramenta que ajude a estruturar informações comerciais, classificar leads segundo critérios definidos e, futuramente, apoiar decisões de prospecção com dados.

## Funcionalidades atuais

- Cadastro de empresas com nome, cidade e segmento.
- Registro da quantidade de vendas e produtos.
- Identificação de loja oficial e status de Mercado Líder.
- Validação de entradas numéricas.
- Cálculo de pontuação (*score*) com regras comerciais.
- Classificação dos leads por prioridade alta, média ou baixa.
- Cadastro de múltiplas empresas durante a execução.
